# Project Harmony Hub

Создай веб-приложение для учета и прогнозирования трудозатрат в проектном бюро.

В приложении должна быть возможность регистрации с вводом имени, фамилии, названия отдела и должности. Также сотруднику задается тег «Полный рабочий день» или «неполный рабочий день».

У всех должностей разные роли для доступа и действий в этом веб-приложении.

 

Должности: директор, модератор, руководитель отдела, сотрудник, офис-менеджер.

 

 

 

1. Страница «Табель рабочего времени»

Доступна для редактирования только для офис-менеджера

Доступна для просмотра всем

В верху страницы заголовок с названием страницы

Страница представляет из себя таблицу, где первый столбец – это ФИО всех сотрудников в алфавитном порядке. Следующие столбцы – по одному на каждый день месяца, в заголовках столбцов число для каждого дня. После этих столбцов идет столбец «часы», в котором суммируется число отработанных за месяц часов, последний столбец – «р.дни», в котором суммируется количество отработанных рабочих дней.

Столбцы с днями, на которые выпали выходные, закрашены серым. При этом у офис-менеджера есть возможность вручную поменять статус столбца на рабочий день или наоборот на выходной.

На странице отображается табель только за один месяц, наверху есть кнопки для выбора месяца и года, который требуется отображать. Можно выбрать для отображения месяца на год вперед от текущей даты и все месяцы за 2025 год. Есть стрелочки для последовательного переключения между месяцами.

Также есть кнопка для фильтра сотрудников по названию раздела или по названию проекта, над которым они работают.

Под этими кнопками написано «Табель АРВ *месяц* *год* (норма *Число N*  р.д./*Число X* ч)

Где *Число N* - количество рабочих дней (не выходных) в текущем месяце

*Число X* = *Число N* *8

Под таблицей отображается легенда условных обозначений к таблице:

«Условные обозначения:                        

Б - больничный лист (только для офис-менеджера)

Н - неявка б (для остальных пользователей)

ОТ - отпуск оплачиваемый     

ДО - отпуск "за свой счет"       

8 - отработанное время, час  

НН - неявка     

ОЖ - отпуск по уходу за ребенком    

У - учебный отпуск»    

 

У офис-менеджера есть возможность вручную изменить статус каждой ячейки в таблице – на любой статус из легенды условных обозначений, или ввести вручную число отработанных часов.

При этом фон ячейки заливается цветом в зависимости от установленного статуса – для каждого статуса разные цвета.

Статус ячейки меняется через правую клавишу мыши, можно зажать левую клавишу мыши и выделить сразу несколько ячеек в одной строчке и сразу задать им всем один статус.

Если у сотрудника стоит тег «Полный рабочий день», то у всех ячеек в будние дни до текущей даты, в которых не был вручную изменен статус, автоматически ставится число «8». Офис-менеджер имеет возможность вручную ввести в каждую ячейку любое число.

 

Справа сверху страницы есть кнопки для экспорта и импорта данных в эксель.

При экспорте экспортируется табель за  месяц, в верху листа надпись «Табель АРВ *месяц* *год* (норма *Число N*  р.д./*Число X* ч). Под табелью легенда условных обозначений.

Есть возможность выгрузить сразу несколько месяцев, в этом случае каждый месяц экспортируется в отдельный файл. Файл при этом называется «АРВ_Табель_*Год*_*Месяц*»

 

Также есть возможность пакетного импорта данных для заполнения это табели сразу за много месяцев и дней в формате экселя.

 

Только у офис-менеджера есть кнопка «Добавить нового сотрудника» с возможностью добавления нового сотрудника. В этом случае нужно заполнить данные нового сотрудника. Также есть возможность скрыть кого-то из сотрудников (уволить)

3. Страница «Проекты»

Вверху страницы заголовок с названием страницы

«Табель всех проектов»

Над табелью кнопка с годом и стрелочками для последовательного переключения между годами

Табель представляет из себя календарь на год, где одна ячейка = один месяц. При этом в одной ячейке одновременно может быть несколько проектов = строчек. Проект отображается как продолжительная задача в гугл календаре – если проект длится несколько месяцев, то строчка проекта растягивается на несколько ячеек-месяцев. У строчки разных проектов – разный цвет. У проектов могут быть временные паузы, но при этом это будет всё еще один проект. Можно растягивать проекты за «ручки» - из-за этого будет меняться дата начала или конца проекта. В этой табели есть возможность создать новый проект как задачу в гугл календаре (потребуется ввести только название проекта).

 

Кнопка «Добавить новый проект» сразу просит ввести название нового проекта. Создавать новые проекты могут только люди из раздела «ГИП», руководители отделов, директор или модератор.

Под этой кнопкой идет список всех проектов. Будущие проекты – синие, Текущие – зеленые, Завершенные - белые

Каждый проект – отдельная страничка.

На страничке проекта сверху заголовок – название проекта

У редактора странички есть возможность добавить небольшую картинку проекта

У проекта указывается тег стадии проекта – «Концепция», «ПД» или «РД».

Поле ввода для даты начала проекта

Поле ввода для срока сдачи проекта

Поле ввода для срока ближайшей промежуточной цели проекта

Табель плана работ по проекту:

Табель представляет из себя таблицу, где первый столбец – это ФИО всех сотрудников или подрядчиков, которые участвую в проекте в алфавитном порядке. Второй столбец – название отдела (раздела). Следующие столбцы – по одному на каждый день месяца, в заголовках столбцов число для каждого дня.

Столбцы с днями, на которые выпали выходные, закрашены серым. При этом если на странице 1 офис-менеджер вручную поменял статус столбца на рабочий день или наоборот на выходной – такой же статус для числа применяется на странице проекта.

На странице отображается табель только за один месяц, наверху есть кнопки для выбора месяца и года, который требуется отображать. Можно выбрать для отображения месяца на год вперед от текущей даты и все месяцы за 2025 год. Есть стрелочки для последовательного переключения между месяцами.

Также есть кнопка для фильтра сотрудников или подрядчиков по названию раздела, над которым они работают.

У людей из раздела «ГИП», директора, модератора или руководителей отделов есть кнопка «Добавить сотрудника на проект» с возможностью добавления сотрудника или подрядчика со страниц 1 или 3.

Под таблицей отображается легенда условных обозначений к таблице:

«Условные обозначения:                        

Б — больничный лист для офис-менеджера; Н — неявка б для остальных (серое)

ОТ - отпуск оплачиваемый (серое)    

ДО - отпуск "за свой счет" (серое)      

У - учебный отпуск (серое)

Р – в работе (зеленое)»           

В табель проекта статусы отсутствий автоматически переносятся из исходных табелей с учётом прав текущего пользователя.

Люди из раздела «ГИП», директоры, модераторы или руководители отделов могут вручную изменить статус каждой ячейки в таблице – на статус «Р».

При этом фон ячейки заливается цветом в зависимости от установленного статуса – для каждого статуса цвета из легенды обозначений.

При этом можно задать статус «Р» для ячейки, у которой уже стоит статус отсутствия, но границы ячейки подкрасятся красным цветом, обозначая конфликт.

Если сотрудник уже занят в эти дни на другом проекте – границы ячеек подкрашутся желтым цветом.

Статус ячейки меняется через правую клавишу мыши, можно зажать левую клавишу мыши и выделить сразу несколько ячеек в одной строчке и сразу задать им всем один статус.

Весь столбец с датой ближайшей промежуточной цели проекта подсвечивается границей с золотым цветом.

Также вверху страницы проекта есть кнопка для переключения вкладки табели проекта на вид по годам, где одна ячейка  = целый месяц. У редакторов страницы есть возможность поменять статус у одной или нескольких ячеек на «Р», в этом случае все будни у сотрудника в выбранных месяцах закрашутся в статус «Р».

 

 

Под табелью проекта есть окно с возможностью для редактора страницы ввода какой-то краткой информации по проекту в свободной форме.
