ARV. ТРУДОЗАТРАТЫ — ИНСТРУКЦИЯ ПО ЛОКАЛЬНОМУ СЕРВЕРУ
=====================================================

Адрес сайта
-----------

http://192.168.88.12:3000

Сайт доступен только с компьютеров в той же локальной сети. На компьютерах
сотрудников ничего устанавливать не нужно — достаточно открыть адрес в браузере.

Чтобы сайт работал
------------------

1. Серверный компьютер должен быть включён.
2. Windows не должна находиться в спящем режиме.
3. Пользователь сервера должен войти в Windows после включения или перезагрузки.

После входа в Windows сервер запускается автоматически. Запуск может занять
несколько минут. Docker Desktop закрывать не нужно.

Если компьютер выключен, спит или после перезагрузки никто не вошёл в Windows,
сайт работать не будет.

Кнопки в папке D:\prog\ARV-Server
---------------------------------

Start ARV.cmd
  Запустить сайт вручную. Повторный запуск безопасен.

Stop ARV.cmd
  Остановить сайт и локальную базу. Данные при этом не удаляются.

ARV Status.cmd
  Проверить, работает ли сайт, база и резервное копирование.

Backup ARV Now.cmd
  Немедленно создать проверенную резервную копию базы.

Check ARV Updates.cmd
  Проверить, появились ли в GitHub изменения от Codex или Lovable.
  Эта кнопка ничего не обновляет и не останавливает.

Update ARV.cmd
  Установить уже проверенные изменения из основной ветки GitHub.

Как обновлять сайт после изменений в Lovable или Codex
------------------------------------------------------

1. Дождаться, пока Lovable или Codex закончит изменение и оно появится в main
   на GitHub.
2. Дважды щёлкнуть Check ARV Updates.cmd.
3. Если найдено обновление, предупредить работающих пользователей: сайт будет
   недоступен несколько минут.
4. Дважды щёлкнуть Update ARV.cmd.
5. Не закрывать окно, пока не появится сообщение:
   "ARV update completed successfully".
6. Открыть сайт и проверить изменённую страницу.

Перед каждым обновлением автоматически создаётся резервная копия базы. Если
новая версия приложения не соберётся или не запустится, скрипт попытается
вернуть предыдущую рабочую версию. База при обновлении не пересоздаётся.

Если обновление завершилось ошибкой, не удаляйте файлы и не переустанавливайте
Docker. Сфотографируйте или скопируйте текст ошибки и передайте его Codex.

Резервные копии
---------------

Автоматическая копия создаётся каждое воскресенье в 03:00. Если компьютер был
выключен, задача выполнится после следующего входа в Windows. Копии хранятся
14 дней в папке:

D:\prog\ARV-Server\backups

Каждая копия проверяется сразу после создания. Рядом хранится файл контрольной
суммы SHA-256.

Копии находятся на том же диске D:, поэтому защищают от случайного удаления или
повреждения базы, но не от поломки всего диска. Позднее желательно добавить
вторую копию на другой локальный диск или сервер. Не отправляйте резервные копии
в облако, почту или сторонние сервисы: они содержат данные приложения.

Если сайт не открывается
------------------------

1. Убедиться, что серверный компьютер включён и не спит.
2. Запустить ARV Status.cmd.
3. Если сайт остановлен — запустить Start ARV.cmd и подождать несколько минут.
4. Снова запустить ARV Status.cmd.
5. Если сайт всё ещё не работает, сохранить текст из окна и последний файл из
   папки D:\prog\ARV-Server\logs, затем передать их Codex.

Не удаляйте папки supabase, docker-data, backups или файлы базы. Не запускайте
восстановление резервной копии самостоятельно поверх рабочей базы.

Адрес сайта и локальная сеть
----------------------------

Сейчас используется адрес 192.168.88.12. Роутер может когда-нибудь назначить
компьютеру другой адрес. Тогда ARV Status.cmd покажет новый адрес, но сотрудникам
потребуется новая ссылка. Чтобы адрес гарантированно не менялся, позднее нужно
закрепить 192.168.88.12 за этим компьютером в настройках роутера.

На роутере нельзя включать перенаправление портов 3000 и 8000 во внешний
интернет. Текущему сайту HTTPS не настроен, поэтому браузер может писать
«Не защищено» — для нынешней локальной HTTP-схемы это ожидаемо. Используйте сайт
только в доверенной офисной сети.

Где находятся данные
---------------------

Рабочая база, учётные записи и резервные копии находятся локально в
D:\prog\ARV-Server. Они не хранятся в Lovable или GitHub.

В GitHub хранится только код приложения. Lovable можно использовать для
изменения интерфейса, но после каждого изменения локальный сервер нужно обновить
по инструкции выше. Такое обновление не должно стирать заполненную базу.

Важные пути
-----------

Сервер и база:      D:\prog\ARV-Server
Резервные копии:    D:\prog\ARV-Server\backups
Журналы ошибок:     D:\prog\ARV-Server\logs
Код приложения:     D:\Prog\Codex\work-balance-studio
